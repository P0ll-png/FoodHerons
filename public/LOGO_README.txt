LOGO PLACEHOLDER
================

The app references the brand logo as /logo.png throughout the UI
(header, footer, store pages, dashboard, auth cards, favicon).

This file is intentionally LEFT EMPTY per the design brief — the logo
area is reserved. To add the real logo:

  1. Drop your logo image into this /public folder.
  2. Name it exactly:  logo.png
  3. Recommended: square (e.g. 512x512), transparent PNG.

Until logo.png exists, each logo slot shows a warm orange→yellow
gradient tile placeholder. The <img> tags hide themselves on load
error, so no broken-image icon appears.
